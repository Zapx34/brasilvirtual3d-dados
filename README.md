# Brasil Virtual 3D: dados do mapa

Dados públicos usados pelo mapa do [Brasil Virtual 3D](https://brasilvirtual3ddeseguidores.vercel.app): contornos dos 5.570 municípios e dos estados do Brasil (malhas do IBGE, simplificadas).

O site carrega o arquivo pelo jsDelivr, numa versão fixa (tag `v1`, `v2`…). Cada versão tem um código no nome do arquivo e nunca muda: um arquivo novo sai com outro código e outra tag.

Este repositório não tem código do jogo.
